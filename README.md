# Paradise Nursery

Paradise Nursery is an e-commerce React application for purchasing house plants and gardening products.

## Features
- **Landing Page:** Introduction to Paradise Nursery with an interactive "Get Started" button.
- **Product Catalog:** Categorized listing of plants with descriptions, prices, and direct "Add to Cart" actions.
- **Shopping Cart:** Real-time cart management to adjust item quantities, calculate total costs, and view item subtotals.
- **State Management:** Powered by Redux Toolkit for seamless cart state updates.
